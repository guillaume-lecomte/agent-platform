# @agent-platform/durable-runner

Runs an agent task as a list of saved steps, so that a crash, a restart or a human approval never loses
progress and never repeats a side effect. The design and its guarantees are in
[ADR 0005](../../docs/decisions/0005-durable-execution-semantics.md).

| Piece                                            | Role                                                                                                              |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `AgentRunner.advance(taskId)`                    | Runs the loop until the task finishes, needs approval or is stopped. Safe to call again at any time.              |
| `TaskStore` (`PgTaskStore`, `InMemoryTaskStore`) | Persistence port: tasks, steps, tool-call registry, approvals. Both implementations pass the same contract tests. |
| `TaskService`                                    | What the API calls: create (idempotent), approve, deny, cancel, query.                                            |
| `TaskQueue`, `TaskWorker`                        | BullMQ producer and consumer. A job means "advance this task".                                                    |
| `EventBus` (`RedisEventBus`)                     | Lifecycle events, streamed by the API over SSE.                                                                   |
| `retryTransient`                                 | Exponential backoff for transient provider errors.                                                                |

An agent is described to the runner by an `AgentRuntime`: its definition (prompt, tools, budget), its tool
implementations and, optionally, how to validate and render its input.

```bash
docker compose up -d postgres redis
DATABASE_URL=postgres://agent:agent@localhost:5432/agent_platform_test REDIS_URL=redis://localhost:6379 \
  pnpm --filter @agent-platform/durable-runner test
```

Migrations are generated by drizzle-kit (`pnpm --filter @agent-platform/durable-runner db:generate`) and
applied by `migrateRunner`.
